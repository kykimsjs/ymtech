# Korean Copy — 사람이 쓴 문장

읽는 사람은 스마트팜 시공사, 농가, 지자체 담당자, 투자자다. 이들은 "혁신"이라는 말보다 **무엇을, 얼마나, 어떻게** 하는지를 알고 싶어 한다.

## 0. 절대 규칙

1. **사실을 지어내지 않는다.** 수치, 고객사, 인증, 수상, 날짜는 `docs/`나 사용자가 준 자료에 있는 것만 쓴다. 없으면 `[확인 필요: 실증 농가 수]`처럼 비워 둔다.
2. **클라이언트가 확정한 문구는 바꾸지 않는다.** 기획안의 헤드카피 같은 문구는 고칠 점이 보여도 제안만 한다.
3. **자료끼리 다른 수치는 고르지 말고 묻는다.** 예: 자동 차단 시간은 기획안 10초, 제품소개 30초

## 1. 찾아서 고칠 표현

### A. 과장 수식어 (보이면 바로 고친다)
혁신적인, 획기적인, 차세대, 새로운 패러다임, 선도하는, 한 차원 높은, 최적의, 최고의, 완벽한, 스마트한, 토탈 솔루션, 원스톱, 압도적인, 독보적인, 미래를 여는, 새로운 기준, 게임 체인저

→ 수식어를 빼고 **구체적인 사실**로 바꾼다.

| 고치기 전 | 고친 후 |
|---|---|
| 혁신적인 AI 기술로 스마트팜 안전의 새로운 기준을 제시합니다 | 분전반 전류가 평소와 다르게 오르면 10초 안에 전원을 끊습니다 |
| 최적의 에너지 관리 솔루션 | 시간대별 전력 사용량을 보고 낭비되는 설비를 찾습니다 |

### B. AI 문장 구조 (보이면 바로 고친다)
- **"단순히 ~가 아닌 ~입니다", "~을 넘어 ~로"**: 대비를 연출하지 말고 하는 일을 바로 말한다.
- **셋 나열 강박**: "안전, 효율, 신뢰를 한 번에". 항목이 정말 셋일 때만 셋을 쓴다.
- **한 줄짜리 결론**: "이것이 바로 와이엠이노테크입니다.", "그 답은 여기에 있습니다."
- **질문형 도입**: "화재 걱정, 아직도 하고 계신가요?"
- **재촉하는 마무리**: "지금 바로 경험해 보세요!" 버튼 문구는 동작만 쓴다: `도입 문의`, `소개서 받기`
- **같은 문장 시작 반복**: "와이엠이노테크는 ~. 와이엠이노테크는 ~."
- **대시(—)와 말줄임, 느낌표 남발**

### C. 번역투·공문서투 (두세 개가 같이 보이면 고친다)
| 표현 | 바꿀 방향 |
|---|---|
| ~를 통해 | ~로, ~해서 |
| ~에 있어서 | ~에서, ~할 때 |
| ~하는 것이 가능합니다 | ~할 수 있습니다 |
| ~되어집니다, ~되어지는 (이중 피동) | ~됩니다, ~합니다 |
| ~를 진행합니다 | 실제 동사로 (설치합니다, 점검합니다) |
| ~적인 남발 (효율적인, 체계적인, 지속적인) | 무엇이 어떻게 효율적인지 쓴다 |
| 다양한 | 실제 목록을 쓴다 (온·습도, 불꽃, 침수, 진동) |
| 제공합니다 남발 | 고객이 하는 일로 바꾼다 (볼 수 있습니다, 받습니다) |

### D. 꾸밈 서식
- 문장마다 굵은 글씨, 이모지, 화살표 장식
- 제목을 첫 문장에서 그대로 반복
- 영어 병기 남발: "안전(Safety)·효율(Efficiency)". 영문 페이지가 따로 있으니 국문에는 영어를 최소로 쓴다.

## 2. 이렇게 쓴다

- **주어와 동사를 분명히.** 누가(모듈이, 웹 플랫폼이, 담당자가) 무엇을 하는지
- **한 문장에 정보 하나.** 본문 문장은 40자 안팎. 길어지면 나눈다.
- **숫자에는 단위와 출처를 붙인다.** "측정 오차 ±2% (KETI 시험)"
- **업계 용어는 그대로 쓰되, 처음 한 번만 풀어 쓴다.** "MCCB(배선용 차단기)", 이후에는 MCCB
- **문체를 통일한다.** 본문은 합니다체, 제목·버튼·라벨은 명사형이나 짧은 동사형
- **고객이 겪는 장면으로 쓴다.** "새벽에 분전반 온도가 오르면 담당자 휴대폰으로 알림이 갑니다"

## 3. 작업 순서

1. **표시하기**: 전체를 읽고 1장의 표현을 모두 표시한다. A·B는 하나만 보여도 고치고, C·D는 여러 개가 겹칠 때 고친다.
2. **다시 쓰기**: 근거 있는 내용은 모두 남긴다. 줄이거나 합치거나 순서를 바꿔도 되지만 **사실을 새로 더하지 않는다.**
3. **점검하기**: 소리 내어 읽듯 다시 본다. 원문 대비 빠지거나 더해진 사실이 없는지, 고친 뒤에도 남기 쉬운 표현(대비 구조, 셋 나열, 대시, 굵은 글씨)이 없는지 확인한다.
4. **결과 보고**: 고친 문구와 함께 `[확인 필요]`로 남긴 항목, 클라이언트 확정 문구에 대한 제안을 따로 적는다.

## 4. 영문 (content/en.ts)

같은 원칙을 쓴다. 특히 다음을 피한다: delve, crucial, pivotal, seamless, cutting-edge, revolutionize, empower, unlock, elevate, landscape, testament, "not just X but Y", 세 항목 나열, em dash 남발.
국문을 직역하지 말고, 해외 B2B 구매 담당자가 읽는 문장으로 쓴다.
